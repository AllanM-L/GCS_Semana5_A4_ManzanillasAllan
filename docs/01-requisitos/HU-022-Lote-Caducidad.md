# Historia de Usuario: HU-022

## Título
Registro de Lote y Fecha de Caducidad en Productos Perecibles

## Descripción
**Como** usuario del sistema de inventario
**Quiero** registrar el número de lote y fecha de caducidad de productos perecibles
**Para** cumplir con la normativa sanitaria y garantizar la trazabilidad

## Criterios de Aceptación
- [x] El campo "Lote" es obligatorio (alfanumérico, máx 20 caracteres)
- [x] El campo "Fecha de Caducidad" es obligatorio (formato DD/MM/YYYY)
- [x] Los campos aparecen en el formulario de registro de productos
- [x] Los campos aparecen en los reportes de stock
- [x] Los campos aparecen en la exportación a Excel/CSV
- [x] No se puede guardar un producto sin estos datos
